# TSG Web Development Project 01 - Personal Portfolio

## Description
A single-page responsive personal portfolio built with HTML5, CSS3 and vanilla JavaScript.

## Features
- Sticky navigation with smooth-scroll sections
- Hero section with developer illustration and CTA
- 80-120 word About section
- Download CV button
- Six skills with icons and progress indicators
- Three project cards with original local SVG illustrations
- Contact form with JavaScript validation
- Social links and footer
- Mobile navigation
- Dark/light mode
- Scroll-to-top button
- Responsive layouts for 360px, 768px and desktop widths

## Tech Stack
HTML5, CSS3, Flexbox, CSS Grid, JavaScript ES6, Google Fonts, Font Awesome, Git/GitHub.

## Setup
1. Download or clone the repository.
2. Add your actual `cv.pdf` in the project root.
3. Replace placeholder GitHub, LinkedIn, email and project links in `index.html`.
4. Open `index.html` in a browser.

## Assets
The project illustrations are original local SVG files created for this portfolio. Font Awesome and Google Fonts are loaded from their respective CDNs.
