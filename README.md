# TSG Web Development Project 01 — Personal Portfolio

A fully responsive single-page personal portfolio website built with **HTML5, CSS3, and vanilla JavaScript** — no page builders, no frameworks.

## 🔗 Live Demo

**[View Live Portfolio](https://ammarabatool-portfolio.vercel.app/)**
## ✨ Features

### Core Sections
- **Navigation Bar** — Fixed, with smooth scroll links (Home, About, Skills, Projects, Contact)
- **Hero Section** — Name, tagline, professional photo, and CTA buttons
- **About Section** — Bio (80–120 words) with downloadable CV button
- **Skills Section** — 6+ skills with icons and progress bars
- **Projects Section** — Grid of project cards with images, titles, descriptions, and links
- **Contact Section** — Styled form with JavaScript validation, plus email and social links
- **Footer** — Copyright line and social icons

### Design & Interaction
- **Fully Responsive** — Optimized for 360px, 768px, and 1440px breakpoints
- **Dark / Light Mode Toggle** — JavaScript-powered theme switcher with localStorage persistence
- **Mobile Menu** — Hamburger toggle for small screens
- **Scroll-to-Top Button** — Appears after scrolling, smooth scroll back to top
- **Hover Effects** — Buttons, cards, nav links, social icons
- **Smooth Scrolling** — CSS `scroll-behavior: smooth` for in-page navigation
- **Active Nav Link Highlighting** — Current section highlighted in navbar on scroll
